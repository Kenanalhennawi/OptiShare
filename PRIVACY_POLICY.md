# OptiShare Privacy Policy

_Last updated: 22 August 2026_

OptiShare is designed for direct local file transfer between devices. The application does not require an account and does not require files to be uploaded to a cloud service.

## Data processed on the device
OptiShare may access files, photos, videos, nearby Wi-Fi devices, camera input for QR pairing, and local network state only when required for features the user chooses to use. This information is processed locally to select content, discover a receiving device, establish a direct connection, and transfer the selected content.

## File contents
Files selected for transfer are sent directly to the receiving device over the local peer-to-peer connection. OptiShare does not intentionally upload transferred files to a developer-operated server.

## Encryption
OptiShare 2 uses an ephemeral elliptic-curve key exchange and authenticated AES-GCM encryption for its application transfer protocol. Received files are verified before being published to the destination folder.

## Accounts, advertising and tracking
The current OptiShare 2 application does not require user registration and does not include advertising or third-party analytics/tracking SDKs.

## Permissions
- Nearby Wi-Fi devices / location on older Android versions: device discovery and Wi-Fi Direct connection.
- Photos and videos: in-app media selection when the user opens those categories.
- Files/storage on older Android versions: selecting and saving content.
- Camera: optional QR pairing.
- Notifications / foreground service: keeping an active transfer visible and running while the application is not in the foreground.

## Local history and resume state
OptiShare may store transfer history, device display name, partial transfer data, and confirmed resume offsets locally on the device. Partial data is used so interrupted transfers can continue instead of restarting from zero.

## Data sharing
OptiShare does not sell personal data. Selected file content is shared only with the receiving peer chosen by the user as part of the transfer operation.

## Security
No software can guarantee absolute security. OptiShare uses authenticated encryption, per-session ephemeral keys, integrity verification, bounded protocol framing, and local-only transfer design to reduce risk.

## Children
OptiShare is a general-purpose file transfer utility and is not specifically directed at children.

## Changes
This policy may be updated when application behavior, permissions, or distribution requirements change. The published application should link to the current hosted version of this policy.
